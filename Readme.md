# 🏋️ Workout Buddyyy

**Workout Buddyyy** is a modern fitness and workout web application designed to help users stay consistent with their fitness journey. The project provides an easy-to-use interface for exploring workouts, maintaining fitness routines, and keeping track of training activities.

🔗 **[Live Demo Frontend](https://workout-buddyy.vercel.app/)**
🔗 **[Live Demo Backend](https://workout-buddyy.onrender.com/)**

---

## 📌 About The Project

Workout Buddyyy was built to provide users with a simple and engaging platform for managing their workout journey.

The main goal of this project is to combine a clean user interface with useful workout-related functionality while providing a smooth experience across different screen sizes.

This project was also developed as a practical way to strengthen my skills in **frontend development, responsive UI design, component-based development, API integration, and modern web development workflows.**

---

## ✨ Features

* 🏋️ Browse workout and exercise information

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project

```bash
cd Workout-Buddyyy
```

### 3. Install dependencies

Using npm:

```bash
npm install
```

Or using pnpm:

```bash
pnpm install
```

Or using yarn:

```bash
yarn install
```

### 4. Start the development server

```bash
npm run dev
```

The application should now be available at:

```text
http://localhost:5173
```
